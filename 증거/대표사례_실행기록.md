## 필수 확장과 부서 영향의 사용 지점

- **필수 확장(계좌 변경 통제·수취계좌 소유 확인):** 변경 사례 3~5단계에서 계좌 변경 접수가 기존 승인을 재검토로 돌리고, 확인 전 재승인을 차단한다. 정상 사례 4단계와 정보 부족 사례의 해외 계좌 단계에서 수취계좌 확인 없이는 지급이 진행되지 않는다.
- **다른 부서 영향(재무 지급 통제 → 영업 요청):** 정보 부족 사례에서 재무의 판정이 "추가 자료 필요"이면 영업지원의 요청은 소명 대기로 남고 재상신이 차단된다. "충분"으로 바뀐 뒤에만 같은 요청을 재상신해 영업임원 승인을 다시 받는다. 승인권자는 원본 승인 권한 정책을 따르고, 소명 절차는 교육용 가정으로 추가했다.
- **조건 변경의 재검증:** 변경 사례 마지막 단계에서 같은 달 추가 요청으로 관련자 월 합산이 200만원을 넘자 기존 승인 건의 지급이 보류된다.
